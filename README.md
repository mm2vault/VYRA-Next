# VYRA Next

A fresh Android music player project with an original Frosted Glass interface.

## Project status
The first commit establishes the Android/Jetpack Compose foundation and the visual shell. Playback integration is intentionally isolated until the existing VYRA playback modules and their licenses/dependencies have been audited.

## Requirements
- JDK 17
- Gradle 8.9+
- Android SDK 35

## Build
Open the project in Android Studio and sync Gradle. The GitHub Actions workflow will run a debug build on pushes and pull requests.
